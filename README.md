# 帝龙装饰纸智能设计平台

装饰纸设计与生产评估的前端工作台，包含首页、样例库、设计智能体、配墨智能体、生产比对和趋势洞察六个模块。Vue 3 + TypeScript + Vite + Tailwind CSS 4，对齐用户提供模板的技术生态，页面保留原版的布局、配色和交互；组件生态为 Ant Design Vue、Preline、Vue Router 和 Pinia。

## 启动

开发使用 Node.js 22.22.2+（22系）、24.15+（24系）或26+，npm 10+；这是模板锁定的构建工具要求。本地验证环境为Node 24.19。安装依赖后运行：

```bash
npm ci
npm run dev
```

Vue 版本地址为 <http://127.0.0.1:51458/>。迁移期间原 React 目录保持原样，可在 <http://127.0.0.1:51455/index.html> 作为对照；两个地址的浏览器存储互相隔离。

共同依赖按所提供 `vue.zip` 的锁文件精确固定：Vue 3.5.40、Vite 8.2.0、Tailwind 4.3.3、TypeScript 5.9.3、Vue Router 5.2.0、Pinia 4.0.2等，完整清单见 [模板版本契约](config/template-ecosystem.json)。可运行 `npm run test:ecosystem` 检查清单、锁文件和实际安装版本是否一致。

Vite包含Vue、Vue JSX、Vue Devtools、Tailwind四个模板插件。正常开发页面保留产品外观；需要可视化开发工具时，先停止普通开发服务，再运行 `npm run dev:tools`。开发工具不会进入正式构建，存储受限时不影响工作台启动。

构建与查看独立静态版本：

```bash
npm run build
python start-local.py
```

也可运行 `npm run preview`（端口51459）。Python 脚本只提供 `dist`，不会暴露工程源码；`--port` 可指定端口，`--no-browser` 可禁止自动开浏览器。访问者和正式静态服务器不需要 Node.js，构建后的 `dist` 包含完整网页图片。

通过静态服务部署后，也支持普通 HTTP 的公网 IP 或域名访问。ID 生成兼容普通 HTTP，无需手工修改发布页面。普通 HTTP 下浏览器不提供 Web Locks，刷新后的未完成任务仍按原有规则显示“状态待确认”，需确认其他窗口状态后再重试；支持 Web Locks 的环境保留原有运行归属检测。

## 使用流程

1. **样例库**：检索 2,990 条公共样例（原有100条演示档案和新增2,890张纹理素材），或导入自己的 ZIP 样例包。业务资料可在导入时提供，也可导入后补充；自己的样例支持编辑和删除。
2. **设计智能体**：选择样例或上传图片，进行相似检索、小样补全、色彩风格迁移或示例候选推荐。保存候选后，可从首页打开任务继续查看；已入库候选可关联到其他任务。
3. **配墨智能体**：分析图片色层、查看合成还原与初始配墨建议，调整单层重量并导出建议单。新配墨操作保存图片、分析结果和参数，可从首页“配墨操作”打开恢复。
4. **生产比对**：上传设计图和实物图，选定对应区域后进行原始分辨率比较，查看色差、RGB 偏差、SSIM 和偏色方向，并导出比对报告。生产比对仍通过导出报告保留结果，刷新会清空当前比对。
5. **趋势洞察**：筛选、检索演示趋势资料，匹配已有样例并创建设计任务，为下一轮设计提供参考。

历史清理入口：首页点击“设计任务”或“配墨操作”统计，可单条删除或多选批量删除，确认后生效。清理历史不会删除样例库与已保存候选；执行中或状态待确认的任务暂不可清理。当前配墨记录删除后仍可预览、导出，但后续调参不会恢复该历史。

设计运行时显示当前处理阶段与进度，支持取消并在原任务上重新执行。进度表示处理步骤完成比例，不是剩余时间预测；PNG 编码等同步步骤需结束后才能响应取消，不会保留取消任务的部分候选。

样例包导入不设 500 条数量上限，仍保留 ZIP 100 MB、解压内容 150 MB 及单图 30 MB / 4000 万像素限制。导出保持现有行为，不新增数量或体积限制。

样例包准备方式见 [样例包格式说明](public/样例包格式说明.txt) 和 [制作自己的样例包](public/制作自己的样例包.txt)。仓库提供可导入的 [示例样例包](public/示例样例包.zip)；`public/demo-pair/` 提供模拟设计图与实物图，便于体验生产比对。

## 数据与当前能力

- 图片分析在浏览器内执行。导入样例、设计任务和配墨记录保存在当前浏览器的 IndexedDB，不上传服务器，不与其他访问者共享，也不会随 Git 提交上传。
- 同一浏览器、同一网站地址的标签页通过通知自动更新本地记录，不整页刷新。编辑中的表单保留原输入，记录被修改或删除时提示冲突；保存前在数据库事务内校验版本，避免旧页面覆盖新数据或恢复已删除记录。配墨历史在其他页面更新后，当前预览保留，需重新加载最新记录再调参。不支持通知时可通过重新聚焦页面或手动刷新更新，保存冲突检查仍有效。此功能不提供跨设备或跨用户同步。
- 浏览器保存的数据按访问地址区分。换浏览器、换端口、换域名或清除网站数据后，不会自动带上原地址的记录；样例可通过 ZIP 导出备份，样例包不包含设计任务与配墨历史。
- 原有100条样例和趋势信息保留演示标识。新增2,890张公共纹理来自Texture Ninja、TexturesForFree、ambientCG和Poly Haven，保留来源及CC0许可链接；与原库重复的30个来源未再次添加。新增素材不含客户、配方和生产记录，配墨仍需按选定图片运行现有算法。
- 公共样例按材质分类，每页24条，支持前后翻页和跳页；搜索/分类会回到第一页。列表只读取当前页缩略图，点击查看完整网页展示图。展示图不超过720×540、缩略图不超过360×270，保持比例，无拉伸或裁剪；本地来源原文件未上传。
- 相似检索使用离线调用现有图像算法得到的平均色、明暗和纹理摘要；这些不是模型训练结果或生产测量值。网页启动不会批量下载公共图片。自己的样例仍只保存在当前浏览器，公共素材不能由访问者编辑或删除。
- 小样补全与风格迁移使用本地图像算法；示例候选推荐从已有样例中筛选，未接入真实 AI 生成或联网趋势研究、预测。
- 风格迁移保持原图分辨率与比例；小样补全按原始纹理尺度扩展画布（横向三倍、五倍或四周三倍宽高）。结果保存为完整分辨率 PNG，页面使用缩略图；点击可适应窗口、100% 查看、缩放拖动，并下载完整图片。目标图片限制为 4000 万像素、单边 32767 像素，超限会显示实际尺寸、像素数和处理上限，提示降低补全倍数或自行缩小原图，不会自动降质。
- 风格候选的“结构相似度”来自原图与该候选的全分辨率灰度 SSIM（7×7 窗口），按百分比显示一位小数，负值显示 0%；没有足够有效区域或计算失败时显示“暂无法计算”。明暗变化也会影响分数，不代表工业生产质量。
- 设计与配墨颜色分析只排除 Alpha 为 0 的像素；半透明内容参与分析。分析缩略图没有可见像素时回查原图，只有原图全部像素完全透明才提示没有可见内容。覆盖率与还原偏差采用同一有效区域，还原图保留原透明度，色层预览不提高原图透明度。历史快照不会自动重算，旧记录如需采用新规则，请重新分析原图。
- 配墨偏差在计算中显示“计算中…”，失败或没有有效结果显示“—”；只有有效分析结果才显示数值，真实零偏差正常显示。生产比对与结构 SSIM 的透明度规则独立于颜色分析，仍要求接近不透明的有效区域。
- 配墨配方是基于图像的初始参考，尚未做工业配墨校准。生产比对没有自动纹理对齐，请核对两图选区是否对应同一处纹理。
- 更新前仅保存元数据的旧配墨记录无法补回当时图片和配方；完整历史恢复适用于带快照的新记录。
- 演示交互：配墨页及导出单对零占比、重复色层给出复核提示，不改变现有算法配方。源样例删除后仍可打开任务查看和评价已保存候选，重新设计需选择新输入。页面刷新后，已停止的任务显示“已中断”并可在原任务上重新执行；无法确认运行归属的旧记录显示“状态待确认”，不会直接断言它已停止。

## 静态部署资源

部署者执行 `npm ci && npm run build`，再将 `dist` 中全部内容同步至原网站根目录。不要仅上传源码的 `index.html`，也不要漏掉图片和 `assets`。浏览器直接刷新 `/samples` 等页面时，静态服务器需要回退至 `index.html`；Nginx 可使用 `try_files $uri $uri/ /index.html;`。无需新增服务端数据库或 Node 常驻进程。

若部署在 `/dilong/` 等子目录，构建前设置 `DILONG_BASE=/dilong/`，路由与图片会使用同一基路径；服务器回退目标也应为 `/dilong/index.html`。不要机械照搬模板的 `/vue/`。

保留同一域名、协议、端口以及原 IndexedDB 名称/版本，可读取旧版个人数据；换地址时不会自动带走数据。样例ZIP只备份样例，不包含设计任务和配墨历史。

开发时如需重建公共素材，运行 `npm run build:textures -- <网页素材包目录>`。默认输出目录已存在时会拒绝覆盖；可用 `--output <临时素材目录> --catalog <临时索引.json>` 先生成并核对。该工具使用 Chrome 和现有图像算法，生成独立展示图、缩略图、来源以及两种兼容索引，不访问原React目录。
