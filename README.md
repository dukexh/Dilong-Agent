# 帝龙装饰纸智能设计平台

面向装饰纸选样、纹理设计与配墨评估的浏览器工作台，支持样例管理、以图搜图、连续纹理扩展、配墨建议和图像比对。

项目采用 Vue 3、TypeScript、Vite 和 Tailwind CSS，图片计算在浏览器本地完成，可构建为独立静态网站。

## 功能概览

| 模块 | 主要功能 |
| --- | --- |
| 首页 | 查看任务、候选方案和配墨记录，恢复历史操作 |
| 样例库 | 浏览 2,990 条公共及演示样例；以图搜图；个人样例 ZIP 导入、导出与资料管理 |
| 设计智能体 | 快速比对排序、小样联想补全、风格迁移孪生、样例自动设计 |
| 配墨智能体 | 色层分析、合成预览、红黄蓝黑自由选墨、重量计算与建议单导出 |
| 生产比对 | 设计图与实物图选区比较、色差与结构指标、差异热图及报告导出 |
| 颜色比对 | 目标色与实涂图比较、配墨建议、色差及偏色方向分析 |
| 趋势洞察 | 浏览演示趋势资料，关联样例并创建设计任务 |

设计结果、连续单元、已保存候选及历史结果支持直接导出 TIF / PSD。小样补全自动制作连续单元，确认后可选择横向 3 倍、5 倍或四周 3×3 扩展。

## 快速开始

### 环境要求

- Node.js：22.22.2 及以上的 22 系列、24.15.0 及以上的 24 系列，或 26.0.0 及以上版本。
- npm：10 及以上版本。
- 浏览器需支持 Canvas、Web Worker 和 IndexedDB。

### 安装与启动

```bash
npm ci
npm run dev
```

访问 <http://127.0.0.1:51458/>。

### 构建与预览

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`，预览地址为 <http://127.0.0.1:51459/>。安装 Python 3 后，也可使用 `python start-local.py` 启动已构建的网站，默认端口为 51458；同一端口只能运行一个服务。

生产部署时发布 `dist/` 中的全部文件，并为页面路由配置 `index.html` 回退。根路径、子目录部署及更新步骤见 [升级与部署指南](MIGRATION.md)。

## 数据与备份

- 个人样例、设计任务和配墨历史保存在当前浏览器，不上传服务器；不同浏览器、域名、协议或端口使用独立的数据空间。
- 保存候选后需在方案评价中采用，才会进入正式样例库，并参与默认检索和推荐。
- 本地样例包仅包含正式个人样例及其资料，包括普通导入样例和已采用候选；不包含公共图库、未采用候选、设计任务或配墨历史。
- 清除网站数据前请导出所需样例与报告。生产比对和颜色比对不提供刷新后的完整会话恢复。

```text
src/
  pages/          业务页面
  components/     共用界面与工作流组件
  core/           图像处理、纹理检索、配方与文件编码
  services/       本地数据服务与业务类型
  stores/         页面状态管理
```

## 当前能力范围

- 纹理检索比较灰度形态、疏密与走向，颜色不参与排序；检索顺序不代表生产质量或识别概率，取样范围和纹理方向会影响结果。
- 小样补全和风格迁移采用本地图像算法；样例自动设计从现有图库推荐候选。当前未接入生成式模型或真实趋势平台。
- 配墨建议是图像分析的初始参考，尚未完成工业配墨校准；色差和结构指标需要结合取样、光照及工艺要求人工复核。
- 工程导出默认 300 ppi、8 位 RGB，保留实际图像像素；连续工程可导出图层及遮罩。修改 ppi 不会增加图像细节，当前不提供生产专色分版或 16 位工程输出。
- 公共图库使用网页展示图，不包含素材的原始高分辨率源文件。图像处理与导出受像素、格式尺寸及浏览器内存限制，超限会提示，不自动缩图。
