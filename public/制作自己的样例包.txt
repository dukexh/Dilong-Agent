样例包制作与导入指南
====================

1. 准备材料

准备需要入库的 PNG、JPG 或 WebP 图片，并为每张图片分配唯一编号和名称。
单张图片不超过 30 MB、4,000 万像素；ZIP 不超过 100 MB，实际解压总量不超过 150 MB。
可以先下载平台提供的“示例样例包”，参照其结构制作。

2. 建立文件夹与清单

新建 images 文件夹，将图片放入其中，再在同级目录建立 manifest.json。
manifest.json 使用 UTF-8 编码，每张图片对应 samples 数组中的一条记录：

{
  "schemaVersion": 1,
  "samples": [
    {
      "id": "MY-001",
      "name": "我的橡木样例",
      "image": "images/sample-001.png"
    }
  ]
}

将 images/sample-001.png 替换为实际文件路径。多张图片增加多条记录，各 id 应保持唯一。
材质、风格、客户、订单、设备、人员及生产资料均可选填，完整字段见“样例包格式说明.txt”。

3. 压缩为 ZIP

同时选中 manifest.json 和 images 文件夹，压缩为 ZIP。
打开 ZIP 检查：第一层应直接看到 manifest.json 和 images，不应再包含外层项目文件夹。
确认清单文件名不是 manifest.json.txt，图片路径、扩展名与实际文件一致。

4. 导入样例

1) 打开平台的“样例库”，点击导入样例文件包的入口。
2) 选择 ZIP，等待图片与资料校验。
3) 查看有效、重复和错误条目；重复编号会跳过，不覆盖已有记录。
4) 点击“确认导入有效记录”。错误条目需修正后重新导入。
5) 点击“查看导入样例”，检查图片和资料是否正确。

样例库使用 ZIP 批量导入；设计页的单图上传用于设计输入，不会自动将原图加入正式样例库。

5. 编辑资料与采用候选

选中个人样例，在档案预览或完整档案中点击“编辑信息”，补充客户、工艺、人员、生产记录和反馈后保存。
内置公共及演示样例为只读资料；样例编号、原图和算法参考配方不能通过资料编辑直接修改。

设计页保存的候选先进入“方案评价”。评价为“已采用”后，才会显示在正式样例库中；待评价、需调整及未采用候选仍保留在方案评价中。

6. 导出与转交

使用样例库中的本地样例包导出入口下载 ZIP。转交或备份时，请先在目标浏览器验证导入成功，再处理原浏览器数据。
导出只包含普通导入样例和已采用候选，并保留其业务资料及已有工程参数。
公共图库和未入库候选不在导出范围内；没有正式个人样例时，导出按钮不可用。

导入端仍受单包 100 MB、实际解压 150 MB、单图 30 MB 限制，导出不会自动拆包。大包需要按清单和图片整理为符合限制的多个包后再导入。

样例包不包含设计任务、配墨历史或比对报告。需要留存这些结果时，请使用各页面提供的工程文件、建议单或报告导出功能。

7. 常见问题

找不到清单：检查 manifest.json 是否位于 ZIP 根目录，文件名是否正确。
找不到图片：检查 image 路径是否与 ZIP 内实际路径一致。
JSON 无法解析：使用英文双引号，删除注释和末尾多余逗号，按 UTF-8 保存。
编号重复：为新增样例使用新的唯一编号；重新导入不会覆盖原记录。
体积超限：减少单包图片数量或自行调整图片尺寸，再重新制作 ZIP。
导入后资料未显示：核对字段名称及类型，完整规范见“样例包格式说明.txt”。
